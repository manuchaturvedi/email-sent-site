How It Works

The auto-scheduler automatically scrapes LinkedIn jobs for configured skills/keywords twice daily at 2 AM and 2 PM IST when no users are running automation.

  • Add up to 10-20 skills/keywords below
  • Set the number of scrolls per skill (more scrolls = more jobs)
  • Jobs are saved to the database and visible to ALL users
  • Auto-runs only when no users are actively scraping
